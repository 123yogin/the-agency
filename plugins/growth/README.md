# growth

Agents and skills for getting a product found, chosen, kept and paid for —
plus the business, legal and support work around it.

Start with **`marketing-context`**: it writes `.claude/product-marketing-context.md`,
which every other item here reads first so you never explain the product twice.

Shared rules: no invented statistics, testimonials or results; benchmarks are
labelled as assumptions unless sourced; no dark patterns, vote manipulation or
undisclosed promotion; legal and privacy outputs are guidance for counsel, not
legal advice.

## Agents

| Agent | Use it for |
|---|---|
| `seo-specialist` | Technical SEO, keyword clusters, on-page fixes, cannibalisation, link earning |
| `aeo-strategist` | Visibility in AI assistants: crawler access, llms.txt, citation audits, fix packs |
| `experimentation` | A/B test design (sample size, duration) and honest ship/no-ship readouts |
| `lifecycle-email` | Onboarding, nurture, re-engagement and win-back flows; deliverability; consent |
| `outbound-strategist` | ICP, buying signals, account tiers, multi-channel sequences, cold email |
| `customer-support` | Support replies and macros that acknowledge, resolve and commit precisely |
| `customer-success` | Health scores, churn signals, save plays, cancel flows, dunning, QBRs |
| `privacy-officer` | GDPR / UK GDPR / CCPA: lawful basis, DPIAs, data maps, DSARs, breaches, vendors |
| `general-counsel` | Contract triage, term sheets, IP hygiene, regulatory triggers — questions for your lawyer |
